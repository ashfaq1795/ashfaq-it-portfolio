My direction is cloud engineering. I am AWS Cloud Practitioner certified and now working on Microsoft Azure, building cloud skills to complement the servers, identity and networks I run every day.

Projects

Hands-on lab projects built to practise enterprise infrastructure design. Both are lab environments, not production deployments.

Networking lab

Five-Department Enterprise Network

Objective: Design a segmented office network where five departments are isolated from each other yet can reach shared services.

My contribution: Planned the topology and IP addressing, configured the switches and routing, and verified connectivity between departments.

  • Cisco Packet Tracer
  • VLANs
  • 802.1Q trunking
  • Inter-VLAN routing
  • IPv4 subnetting

Key detail: department separation with controlled inter-VLAN access, tested with ping and tracert.

Windows Server lab

DNS, Domain Controller and Active Directory

Objective: Build a working Windows domain from a clean server, the way a small company would start.

My contribution: Installed and configured the server, set up DNS, promoted the domain controller, then managed OUs, users, security groups and client domain joins.

  • Windows Server
  • DNS
  • Active Directory DS
  • OUs and groups
  • Domain join

Key detail: name resolution configured first, since a domain controller depends on it.
